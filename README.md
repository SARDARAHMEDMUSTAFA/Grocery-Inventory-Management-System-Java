🛍️ Grocery Inventory Management System (Java)
📋 Overview

A Java Swing-based GUI application for managing grocery products efficiently.
It allows users to:

Add new grocery products

Update existing ones

Delete last added item

View all products in a table

Automatically calculate total = quantity × price per unit

Save and load data using file handling

🧠 Concepts Used

Data Structures: ArrayList for storing products

OOP Concepts: Classes, Objects, Encapsulation

GUI: Java Swing (JFrame, JTable, JButton, JTextField)

File Handling: Read/write product data in text file

🧩 Features

✅ Auto Product ID Generation
✅ Simple & Interactive GUI
✅ File-based Data Storage (no database required)
✅ Real-time updates in JTable
✅ Error Handling for invalid inputs

Language: Java (JDK 8 or higher)

IDE: NetBeans

Libraries: javax.swing, java.io

🚀 How to Run

Open project in NetBeans

Run InventoryGUI.java

Add or load products using GUI buttons

Data auto-saves in inventory.txt
